# Features

Código organizado por domínio funcional. Cada feature deve concentrar sua composição de UI e casos de uso, reutilizando `components`, `services`, `repositories`, `models` e `dtos` compartilhados.

Domínios previstos no roadmap: `auth`, `users`, `permissions`, `roles`, `unavailability`, `events`, `schedules`, `setlists`, `songs` e `audit`.
